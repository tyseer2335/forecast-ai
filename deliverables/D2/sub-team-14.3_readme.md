### What is the product? ⚙️ 
The project aims to simplify the process of collecting real-time global data and detecting biases in AI-generated forecasts. It automates data gathering from sources like news and social media, structures it for AI analysis, and visualizes both the forecasts and any biases in the data. This makes AI predictions more transparent and helps improve their accuracy by addressing potential cognitive biases.

Developed in collaboration with the Machine learning Group at the University of Toronto, the platform enhances a custom AI model for forecasting major events. Users can input questions, and the system will generate predictions, showing how the data and AI's reasoning might influence the results, making AI forecasting clearer and easier to understand.

### How to Install

##### 1. Ensure you have Node.js, npm, and an IDE such as VS Code installed.

- Node.js and npm install guide: https://docs.npmjs.com/downloading-and-installing-node-js-and-npm
- VS Code Install: https://code.visualstudio.com/download

##### 2. Clone the repository and change to the D2-14.3 branch:

1. **Open a new terminal and run:**
   `git clone https://github.com/csc301-2024-f/project-14-ml-cs-uoft.git`

2. **Place the frontend `.env` file** from the email provided into the frontend folder. Ensure it is located at:  
   `project-14-ml-cs-uoft\forecast-ai\frontend`

3. **Navigate to the project directory:**
   `cd .\project-14-ml-cs-uoft\`

4. **Switch to the D2-14.3 branch:**
   `git checkout D2-14.3`

5. **Navigate to the frontend directory:**
   `cd .\forecast-ai\frontend`

6. **Install all dependencies:**
   `npm install`

7. **Run the development server:**
   `npm start`

Now you should see the app running on `localhost`.

- Alternatively you can look at the entire application so far at https://forecastai.netlify.app/
